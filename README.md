# KaminoDatasetGenerator
A pipeline to generate type 4 clones using LLMs

Required libs (install in this order): 
* tree_sitter
* tree-sitter-python==0.21
* [MS C++ build tools](https://visualstudio.microsoft.com/pt-br/visual-cpp-build-tools/) -- make sure to install Desktop development with C++ (include Win 10/11 SDK and C++ CMake tools for Windows)
* codebleu
